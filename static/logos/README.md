# Logos

Affiliation logos and project/software logos live here.

Project and software cards on the home page show a logo when the matching file
exists; otherwise they fall back to an index number (projects) or the initial
letter (software), so missing logos never look broken.

## Expected project / software logos
- orchestrai.png       (already added)
- quantumdotspace.png
- qd-builder.png
- minibse.png
- auto-fox.png

Transparent PNGs work best (they sit on a white rounded tile). To change a
filename, edit the matching `logo:` path in `src/lib/content/site.ts`.
