# Public web logos

This directory contains optimized images served directly by the website. The original
high-resolution artwork lives in `assets/source-logos/`.

Do not overwrite generated `*-web.png` or `infantelab-*.png` files manually. Replace the matching
source artwork and run:

```sh
npm run assets:build
```

BCMaterials and Ikerbasque affiliation logos are currently maintained directly in this directory
because they are already reasonably sized.
